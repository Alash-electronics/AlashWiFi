# Changelog

## 1.1.1
- Примеры: описание в начале каждого примера на русском, казахском и английском.

## 1.1.0
- `addParam()`, `param()`, `setParam()`: свои поля на странице портала (адрес MQTT, токен бота, имя устройства), сохраняются вместе с сетью (Preferences на ESP32, EEPROM с контрольной суммой на ESP8266).
- Если сеть уже сохранена, на странице портала имя сети не обязательно: можно поправить только свои поля.
- `forget()` забывает сеть, но не свои поля. Новая ошибка `ERR_BAD_PARAM`, `clearError()`.
- Из 1.0.0: Первый выпуск: подключение к Wi-Fi для ESP32 и ESP8266 с понятной причиной неудачи (нет сети, неверный пароль, слабый сигнал).
- Автопереподключение с растущей паузой 5, 10, 20, 40, 60 секунд.
- Сохранение сети (Preferences на ESP32, EEPROM с контрольной суммой на ESP8266), `autoConnect()` и портал настройки с телефона: список сетей, captive-страница, защита от неверного ввода.
- Сканер сетей, `diagnose()` на русском, казахском и английском.
